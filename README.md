Breast Cancer Research Analysis Dashboard
Professional Portfolio Case Study
Author: Razaq Idris
Tool: Microsoft Power BI
Domain: Healthcare Analytics
1. Executive Summary
This case study demonstrates the end-to-end development of an interactive Power BI dashboard for breast cancer research. The dashboard transforms raw clinical data into actionable insights using KPIs, charts, slicers, and tables.
2. Business Problem
Healthcare professionals need an efficient way to compare benign and malignant diagnoses and understand tumor characteristics.
3. Project Objectives
• Build an interactive dashboard
• Track diagnosis distribution
• Compare tumor metrics
• Support evidence-based decisions
4. Dataset Description
The dataset contains diagnosis labels (Benign/Malignant) and tumor measurements including radius, texture, area, perimeter, compactness, concavity, symmetry and related features.
5. Data Preparation
Removed duplicates, handled missing values, validated data types, standardized diagnosis labels, created calculated measures in DAX, and optimized the data model.
6. Dashboard Design
The dashboard combines KPI cards, slicers, bar charts, scatter plot, pie chart and a matrix to present summary and comparative analysis.
